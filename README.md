# EMBODY-Mapas-Corporales

Repositorio con instrucciones para la ejecución del EMBODY Mapas corporales desde una interfaz html. Se describe el acceso a los datos y las instrucciones de la tarea. 
La información de acceso la encontrarán en el manual de pdf.

### Desplegar el Wiki

El wiki se despliega automáticamente mediante GitHub Actions. Para más información, consulta [WIKI_DEPLOYMENT.md](WIKI_DEPLOYMENT.md).

**Inicio rápido**:
1. Edita archivos en el directorio `wiki/`
2. Haz commit y push a `main` o `master`
3. El wiki se actualiza automáticamente

## 📁 Estructura del Repositorio

- `data/` - Archivos de datos (adquisición y orden de exposición)
- `wiki/` - Contenido fuente del wiki
- `manual.pdf` - Manual de acceso al sistema
- `Guia_protocol_entrevistador FINAL.docx-8.pdf` - Protocolo para entrevistadores
