## Descripción del Proyecto

EMBODY Mapas Corporales es un repositorio que contiene instrucciones para la ejecución de tareas relacionadas con mapas corporales desde una interfaz HTML. El proyecto incluye:

- Instrucciones detalladas de la tarea
- Datos de adquisición y orden de exposición
- Manuales y guías en formato PDF
- Protocolo para entrevistadores

## Acceso Rápido

- **Manual PDF**: Consulta el `manual.pdf` en el repositorio principal para información detallada de acceso
- **Guía del Protocolo**: Ver `Guia_protocol_entrevistador FINAL.docx-8.pdf`

## Contribuir

Para contribuir a este wiki:

1. Edita los archivos en el directorio `wiki/` del repositorio principal
2. Realiza un commit y push a la rama principal
3. El workflow de GitHub Actions desplegará automáticamente los cambios
