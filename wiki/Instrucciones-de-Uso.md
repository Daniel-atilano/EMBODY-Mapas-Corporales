# Instrucciones de Uso

## Requisitos Previos

Antes de comenzar a usar EMBODY Mapas Corporales, asegúrate de tener:

- Un navegador web moderno (Chrome, Firefox, Safari, Edge)
- Acceso a los archivos del repositorio
- Permisos necesarios para acceder a los datos (ver Manual PDF)

## Configuración Inicial

1. **Clonar el Repositorio**
   ```bash
   git clone https://github.com/Daniel-atilano/EMBODY-Mapas-Corporales.git
   cd EMBODY-Mapas-Corporales
   ```

2. **Revisar los Datos**
   - Los datos se encuentran en el directorio `data/`
   - `adquisicion.csv` contiene información de adquisición
   - `orden_exposicion.csv` define el orden de exposición de las tareas

3. **Consultar el Manual**
   - Abre `manual.pdf` para obtener información detallada sobre el acceso
   - Revisa `Guia_protocol_entrevistador FINAL.docx-8.pdf` para el protocolo de entrevista

## Uso de la Interfaz HTML

### Acceso a la Interfaz

La información específica de acceso se encuentra en el manual PDF incluido en el repositorio.

### Navegación

1. Sigue las instrucciones del manual para acceder a la interfaz
2. Utiliza los controles proporcionados para interactuar con los mapas corporales
3. Sigue el orden de exposición definido en `data/orden_exposicion.csv`

## Protocolo para Entrevistadores

Los entrevistadores deben:

1. Leer completamente la guía del protocolo antes de comenzar
2. Familiarizarse con la interfaz de usuario
3. Seguir el protocolo establecido en `Guia_protocol_entrevistador FINAL.docx-8.pdf`
4. Registrar adecuadamente los datos según las instrucciones

## Solución de Problemas

### Problemas Comunes

- **No se puede acceder a la interfaz**: Verifica los permisos de acceso en el manual
- **Datos no se cargan**: Asegúrate de que los archivos CSV estén en el directorio `data/`
- **Error en el navegador**: Intenta con un navegador diferente o actualiza el actual

## Preguntas Frecuentes

**P: ¿Dónde encuentro la información de acceso?**  
R: La información de acceso se encuentra en el `manual.pdf`.

**P: ¿Qué navegadores son compatibles?**  
R: La mayoría de navegadores modernos son compatibles. Se recomienda usar la última versión de Chrome o Firefox.

**P: ¿Puedo modificar los datos?**  
R: Consulta el manual y las políticas del proyecto antes de realizar modificaciones.
